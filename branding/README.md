# Omarpad logo

设计概念：左侧横屏表示 Linux 主机，右侧竖屏表示通过 USB 接入的 iPad 副屏。两块屏幕重叠成一个紧凑符号，适合项目头像、桌面入口和文档页眉。

名称 **Omarpad** 取自当前工作区目录名；如项目正式名称不同，只需调整字标，图形标志可以继续使用。图形不承诺具体设备型号、解码方式或软件功能。

## 使用规范

- 主色：深海军蓝 `#101A31`、浅紫蓝 `#8494FF`、薄荷绿 `#5CE5D0`。浅色版用 `#6678E8` 和 `#098F87` 增加对比度。
- 图标四周保留至少其宽度的 1/8 留白；小于 48 px 时优先使用应用图标，不使用横版小字。
- 横版字标中的 `LINUX SECOND DISPLAY` 是说明语，可在高度不足时移除。不要拉伸比例或更换两块屏幕的相对位置。
- 可编辑 SVG 字标使用 DejaVu Sans。PNG 和 `omarpad-lockup-outlined.svg` 不依赖本机字体。
