# Omarpad 界面设计与实现边界

更新：2026-10-16。本文件记录本工作区的界面设计与实现状态；既有交互契约和历史实测在 [ipadctl/DESIGN.md](../ipadctl/DESIGN.md)，设备历史与长期验收边界在 [HANDOFF.md](../HANDOFF.md)。本轮的窗口检查和单元测试不等同于充电改档实机验收。

## 结构

延续已经实现的 **460 × 780 小窗、屏幕 / 充电两个页签、常驻托盘和自动副屏开关**。窗口用 Rust + Slint 软件渲染。屏幕页保留画布拖动、方向、亮度、分辨率与设备状态；充电页按当前在线 GUD 设备显示限流和电流。窗口关闭即隐藏；托盘仍可重新打开。

信息从设备与宿主当前读数产生。DFU、GUD、仅维护口和未知产品串使用不同文字；“在线”仅表示对应 GUD USB 设备被枚举，不能替代桌面持续显示、硬解或电池收支证明。画布和写入沿用 `ipadctl/DESIGN.md` 的边界，不在本轮改变 DFU 投放和显示器应用策略。

## Omarchy 外观

启动时读取 `omarchy theme color --all`，从当前主题取得 background、foreground、lighter_background、dark_foreground、accent、red、green 和 yellow。程序每三秒检查主题和字体变化；主题切换期间若读到不完整色板，保留上次完整结果。首次读取失败时使用内置深色回退，状态行不因此宣称硬件故障。

界面背景、卡片、边界、主副文字、强调色与状态色均由语义色派生。色彩只在进程内计算，不写回 Omarchy。正文和辅助文字相对卡片背景至少按 4.5:1 修正，强调色图形至少按 3:1 修正；强调色文字与小字号状态文字另行提亮。颜色之外始终保留状态文字。当前 Labra 深色和 Flexoki Light 浅色的解析与对比修正在离线单元测试中检查。两者的窗口均在本机可见检查；浅色使用离线色板预览，尚未切换宿主实际主题。

正文用系统字体及 Slint 的系统回退链；设备端口、数字和页脚使用 fontconfig 找到的等宽字体。字号和间距依现有小窗比例组织，卡片用柔和描边、留白和单侧状态条分层。短暂的 hover、切换、滑块反馈在系统 `gtk-enable-animations=false` 时关闭；没有循环动画。运行中主题变更一次更新全部 Slint token。

## 充电页状态契约

每个当前在线且机型可识别的 GUD 设备有一张卡片；按 USB 端口绑定维护 ACM。J207 只提供 500 / 1000 / 1500 mA，A7 只提供约 206 / 650–750 mA 两档。按钮高亮表达 **配置目标**，不表示设备已执行。两个同型号设备并存时禁用改档，因为机型 slug 不足以唯一定位用户点的设备。

进入充电页时后台读取，每 60 秒或手动刷新重新采样。读取与写入最多两项并发，同一端口互斥；扫描与界面线程不等待电量计。维护口失联、读取失败、无电量计均有独立文字，显示采样距今时间。A7 正数平均电流才标“充电中”；J207 不显示推测电流。

限流写入先经维护口写 watchdog 目标文件。成功仅显示“目标已提交”。A7 在本次提交之后从寄存器 0x4C0 读到匹配值，才显示“寄存器已回读”；J207 需要新于写前记录、值匹配的 dmesg 看门狗日志，才显示“看门狗已写入”，并明确其不是寄存器回读。提交失败与保存配置失败分别提示。页面不会把一次目标文件写入当作持续充电证明。

## 验收与剩余验证

- 离线：Rust 工作区测试、Slint 编译、色板深浅与错误输入、限流档位和证据判定。
- 本机可见：Labra 下屏幕和充电页均已呈现；三台设备的读取卡片在采样完成后可见。Flexoki Light 离线色板下的充电页也已检查，但不能证明系统主题切换路径。
- Release 离线内存测量（本机，`--measure`，自动投放暂停）：仅托盘 18,532–18,608 KiB，开窗 61,748–61,976 KiB，隐藏后三次重开 30,548–30,728 KiB（29.83–30.01 MiB），二进制 11,721,048 B。隐藏态位于原设计 30 MiB 门槛的测量边缘，不能称为稳定留有余量；同机导入前版本一次测得 29,660 KiB。
- 实机只读：当前三台 GUD 的 A7 限流寄存器值及电量计电流、J207 最近日志已通过新页面显示；J207 维护口 `cat /proc/uptime` 返回两列秒数，第一列可被本次证据门槛解析。此项不证明限流改档成功。
- 待上机：三机型改档、watchdog 下一周期日志、A7 寄存器读回、电池平均电流与断连重连，均不能由这次界面构建替代。
- 待额外检查：在实际浅色 Omarchy 主题及字体缩放下查看布局、键盘焦点与辅助技术可用性。
